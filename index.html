A writing assistant that lives in Microsoft Word

WriteAssist checks spelling, grammar, clarity and tone while you write, explains every suggestion, and rewrites passages with AI when you ask.

Install in three steps

  1. Download your manifest

    The manifest is a small file that tells Word where WriteAssist lives. This one is made for this site.

  2. Add it to Word

    Windows (Word 2016 or later)

    Put manifest.xml in the install folder of the WriteAssist package, then double-click install-windows.cmd. Close Word completely and open it again.

    The installer only writes a per-user setting, so it does not need administrator rights. If the button does not appear, use a shared folder catalogue instead.

    Mac

    Put manifest.xml in the install folder and run install-mac.sh, or copy the file to ~/Library/Containers/com.microsoft.Word/Data/Documents/wef yourself. Restart Word, then choose WriteAssist from Home > Add-ins.

    Word on the web

    Open a document, choose Home > Add-ins > More Add-ins, then My Add-ins > Upload My Add-in, and pick manifest.xml.

  3. Open WriteAssist

    On the Home tab, choose WriteAssist. The panel opens beside your document and checks it straight away. Click any suggestion to jump to it.

What it checks

  • Correctness: spelling, grammar and punctuation
  • Clarity: wordy phrases, long sentences, passive voice
  • Engagement: weak words and clichés
  • Delivery: formality and nonstandard phrasing such as do the needful

Privacy

Style checks run inside Word. Spelling and grammar checks send paragraph text to LanguageTool. AI features send the text you choose to Anthropic using your own Claude API key. Online checking can be switched off in Settings.
